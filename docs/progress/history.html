Progress history

Each panel has its own scale: the solid line is what is implemented, the dashed line what is declared. Library functions are declared in the prx sources. Shader history keeps the metrics separate: "RDNA2 reference shader forms" counts the AMD RDNA 2 instruction forms decoded by the current scanner (tools/rdna2_isa_forms.txt); "gfx1013 reference shader forms" counts the separate gfx1013 profile (tools/gfx1013_isa_forms.txt) and is absent when that profile cannot be measured. It does not replace the RDNA2 reference. "Legacy shader opcode names" counts the archived decoder opcode table against the current AMD RDNA 1 + RDNA 2 instruction list (tools/rdna_isa.txt) and is used only when the current scanner cannot read the archived source. Their totals differ, so compare points only within the same shader panel. One point per UTC day with commits on main, taken at the last commit of the day. Every point is measured with the current tools/progress.py and tools/shader_scan.py rules, so points within each series are comparable across days. The bars and the Functions implemented column show the net change in implemented library functions from one point to the next; the first point is n/a. Hover a day for the exact numbers. history.json records the shader metric for each point. Back to the current progress.
