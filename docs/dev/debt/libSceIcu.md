# libSceIcu technical debt

### Functional locale parsing and metadata

- [LocaleCore.cpp](../../../core/libs/prx/libSceIcu/LocaleCore.cpp) implements six public ICU C entry points: `uloc_getLanguage`, `uloc_getCountry`, `uloc_getScript`, `uloc_getBaseName`, `uloc_canonicalize`, and `uloc_getKeywordValue`. These use typed System V guest signatures with 32-bit length/status fields, copy and overflow semantics, case normalization, locale components, and keyword lookup. Release-active guest tests and Linux ASan/UBSan/leak checks cover bounded buffers, malformed keyword items, and status propagation; 22,647 additional input/capacity combinations were differential-checked against *native desktop ICU 74*. This is a source-compatible subset, not an assertion of PS5 firmware 68 binary equivalence. Long/host-specific aliases, obscure locale grammar, data-driven locale operations, and arbitrary malformed input remain unverified. Neither PS5 hardware calls nor a console trace was available.

### Functional

- [ICU backend](../../../core/libs/prx/libSceIcu/Backend.cmake) (libSceIcu) - the exports that forward to the bundled ICU run [ICU 68.2](https://github.com/unicode-org/icu/tree/84e1f26ea77152936e70d53178a816dbfbf69989) (`release-68-2`, `3rdparty/icu`) with the full ICU data, generated at build time from `icu4c/source/data` by ICU's own tools and linked into the library as `icudt68l`. The console's patch level is not measured on a console: the C++ exports mangle `icu_68`, which fixes the major version only. The console's data set, which may be filtered, is not measured on a console, so available locales, converters and other data-driven lists can differ. Data files are never opened (`udata_setFileAccess(UDATA_NO_FILES)`). [Version.cpp](../../../core/libs/prx/libSceIcu/Version.cpp) still reports 78.1 and the hand-written property functions follow ICU 78.1 data, so results mix ICU 68.2 and 78.1.

- [Default locale, converter and time zone](../../../core/libs/prx/libSceIcu/Backend.cpp) (libSceIcu) - the console's defaults are not measured on a console. `uloc_getDefault` and `ucnv_getDefaultName` throw until the guest sets a default with `uloc_setDefault` or `ucnv_setDefaultName`, and again after it passes NULL or calls `u_cleanup`; the host's locale and code page are never used. ICU-backed exports throw for a NULL locale or converter name without a guest default, for a result ICU reached by falling back to the default locale (`U_USING_DEFAULT_WARNING`) without one, and for a NULL time zone, since no export sets ICU's default zone. `ucnv_setDefaultName` keeps the previous default for a name ICU cannot open, as ICU does. Formatting opens throw for a locale with `@compat=host`: a Windows build of ICU then formats with the host's own number and date settings, a FreeBSD or Linux build ignores the keyword, and which the console does is not measured on a console.

- [unorm2](../../../core/libs/prx/libSceIcu/Normalization.cpp) (libSceIcu) - not measured on a console. `unorm2_getInstance` with a package name throws: it would read a custom `.nrm` file, and the console's data lookup is unknown. `unorm2_openFiltered` copies the guest `USet` when it opens, where ICU keeps a reference, so a later change to the set, which ICU documents as not allowed, is not seen. A null normalizer or status throws where ICU dereferences it. `unorm2_swap` throws: the `UDataSwapper` layout is unknown.

- [Character properties](../../../core/libs/prx/libSceIcu/Properties.cpp) (libSceIcu) - not measured on a console. The `u_is*` predicates, `u_charType`, `u_charDirection`, mirroring, paired brackets, age, combining class, integer and binary properties, property and value names, numeric values, simple case mappings, `u_charName`, `u_charFromName`, `u_getFC_NFKC_Closure` and `ublock_getCode` forward to ICU 68.2 (Unicode 13.0). The hand-written `u_isspace`, `u_charDigitValue`, `u_digit` and `u_getUnicodeVersion` follow ICU 78.1 (Unicode 17.0), so the two groups can disagree for code points assigned after Unicode 13.0. A null status passed to `u_charName`, `u_charFromName`, `u_enumCharNames` or `u_getFC_NFKC_Closure` returns without an error, as in ICU. `u_getBinaryPropertySet` returns a guest `USet` copy of ICU's set, made once per property and kept after `u_cleanup`. `ucpmap_get` and `ucpmap_getRange` take only maps from `u_getIntPropertyMap`.

- [uscript](../../../core/libs/prx/libSceIcu/Script.cpp) (libSceIcu) - not measured on a console. The 11 `uscript_` exports forward to ICU 68.2 (Unicode 13.0 script data). `uscript_getCode` resolves locale IDs only through ICU's likely-subtags data and never reads the default locale. A null status throws in `uscript_getCode` and `uscript_getSampleString`, where ICU dereferences it, and returns as in ICU in `uscript_getScript` and `uscript_getScriptExtensions`.

- [ubidi](../../../core/libs/prx/libSceIcu/Bidi.cpp) (libSceIcu) - not measured on a console. `ubidi_open`, `ubidi_close`, `ubidi_setPara`, `ubidi_getParaLevel`, `ubidi_countRuns`, `ubidi_getVisualRun`, `ubidi_getLogicalRun`, `ubidi_getBaseDirection`, `ubidi_reorderVisual` and `ubidi_getClass` (ICU's internal class lookup without a custom callback) forward to ICU 68.2. As in ICU, `ubidi_setPara` keeps pointers to the guest's text and embedding levels. A null object throws in `ubidi_getLogicalRun`, which reads it before ICU's validity check; the other functions keep ICU's checks. `ubidi_setClassCallback` throws: host ICU would call the guest callback with the host ABI.

- [String case mapping and comparison](../../../core/libs/prx/libSceIcu/CaseMap.cpp) (libSceIcu) - not measured on a console. `u_strToUpper`, `u_strToLower`, `u_strToTitle`, `u_strFoldCase`, `u_strCaseCompare`, `u_strcasecmp`, `u_strncasecmp`, `u_memcasecmp` and `u_caseInsensitivePrefixMatch` forward to ICU 68.2. A NULL locale for upper, lower or title case throws until the guest sets a default, unless ICU would return before mapping. `u_strToTitle` takes a `UBreakIterator` from `ubrk_open` and, as in ICU, leaves it on a text that is gone after the call; with NULL, ICU's word iterator for the locale is used. A null string with a length ICU would read, a null status where ICU dereferences it, or a null second match length with a first throws.

- [ucol](../../../core/libs/prx/libSceIcu/Collation.cpp) (libSceIcu) - not measured on a console. `ucol_open`, `ucol_close`, `ucol_strcoll`, `ucol_strcollUTF8`, `ucol_strcollIter`, the strength and attribute accessors, `ucol_getRules`, `ucol_getReorderCodes`, `ucol_countAvailable`, `ucol_getAvailable` and `ucol_getTailoredSet` forward to ICU 68.2. A NULL locale throws until the guest sets a default; tailorings load without the default locale, so a fallback warning means root. `ucol_strcollIter` calls the guest iterator through a host bridge. A null collator, length, status or iterator function that ICU reads, or a negative index, throws. A tailored set with strings throws: the guest `USet` holds ranges only. `ucol_getKeywordValues` and `ucol_getKeywordValuesForLocale` return guest enumerations (see enumeration sources). `ucol_getContractionsAndExpansions` (always strings), `ucol_swap`, `ucol_swapInverseUCA` and `ucol_looksLikeCollationBinary` (`UDataSwapper`) throw.

- [usearch](../../../core/libs/prx/libSceIcu/StringSearch.cpp) (libSceIcu) - not measured on a console. `usearch_open`, `usearch_getCollator`, `usearch_getMatchedLength`, `usearch_next`, `usearch_reset`, `usearch_setAttribute`, `usearch_setOffset`, `usearch_setPattern` and `usearch_setText` forward to ICU 68.2. A NULL locale is ICU's illegal argument; the collator and ICU's character break iterator load without the default locale. As in ICU, a search keeps pointers to the guest's pattern, text and `UBreakIterator`, whose text it sets. No `usearch_close` export exists, so searches and their collators are never freed. A null status, or a pattern length below -1, which ICU would read before the pattern, throws. With overlapping on, ICU 68.2 returns the same match again without end for a contraction or a supplementary pattern.

- [uidna](../../../core/libs/prx/libSceIcu/Idna.cpp) (libSceIcu) - not measured on a console. `uidna_openUTS46`, `uidna_close`, `uidna_nameToASCII` and `uidna_nameToUnicode` forward to ICU 68.2 (UTS 46 data of Unicode 13.0). `UIDNAInfo` has the same 16-byte layout for the guest and ICU; as in ICU, a `size` field of 16 or more is required and ICU clears every byte it covers after the field. A null status, or a null instance once ICU's argument checks pass, throws.

- [ubrk](../../../core/libs/prx/libSceIcu/BreakIterator.cpp) (libSceIcu) - not measured on a console. The `ubrk_` exports forward to ICU 68.2 and its break rules and dictionaries. Break data loads with `ures_openNoDefault`, so a fallback warning means root; `@ss=standard` sentence suppressions use `ures_open` but ignore a default-locale fallback, so the result never depends on the default. A NULL locale throws until the guest sets a default. As in ICU, an iterator keeps pointers to the guest's text and binary rules. A null iterator or status ICU reads, a NULL status vector ICU would write, a negative index or the index one past ICU's locale array throws. `ubrk_setUText` and `ubrk_refreshUText` throw (no guest `UText` exists: every `utext_` export throws), as does `ubrk_swap` (`UDataSwapper`).

- [Enumeration sources](../../../core/libs/prx/libSceIcu/EnumerationSources.cpp) (libSceIcu) - not measured on a console. `uloc_openKeywords`, `uloc_openKeywordList`, `uloc_openAvailableByType`, `ucurr_openISOCurrencies`, `ucurr_getKeywordValuesForLocale`, `ucnv_openAllNames`, `ucnv_openStandardNames`, `ucal_openTimeZones`, `ucal_openTimeZoneIDEnumeration`, `ucal_getKeywordValuesForLocale`, `unumsys_openAvailableNames`, `uenum_openCharStringsEnumeration`, `uenum_openUCharStringsEnumeration` and the two `ucol_getKeywordValues` exports forward to ICU 68.2 and wrap ICU's enumeration in a guest-allocated `UEnumeration` whose callbacks forward to it; strings stay valid until the next call, as in ICU. - [Number formats](../../../core/libs/prx/libSceIcu/NumberFormat.cpp) (libSceIcu) - not measured on a console. The `unumsys_`, `ufieldpositer_`, `unum_` and `uplrules_` exports forward to ICU 68.2. A NULL locale throws until the guest sets a default. ICU loads number data with `ures_open`, which falls back through the default locale for a language without data, often without a warning: such an open throws without a guest default, as does a rule-based style for a language without `rbnf` data, and a format opened that way under a guest default throws once the default is cleared. An explicit `@numbers=` system needs no locale data; plural rules never use the default. A null object or status ICU reads, or a NULL decimal string ICU would read, throws. `uplrules_getKeywords` returns a guest enumeration.

- [List, display name and relative date formats](../../../core/libs/prx/libSceIcu/TextFormat.cpp) (libSceIcu) - not measured on a console. - [unumf](../../../core/libs/prx/libSceIcu/NumberFormatter.cpp) (libSceIcu) - not measured on a console. The eight `unumf_` exports forward to ICU 68.2 number skeletons. - The 19 named stubs declared in [Identified.hpp](../../../core/libs/prx/libSceIcu/Identified.hpp) carry the ICU C API names whose `tools/nid_names.py` hash equals the inventory NID; the names were taken from the identifiers of the ICU 78.1 `common`, `i18n` and `io` sources. A name match does not show that the console function has ICU's prototype or behavior. Most of them read Unicode property, case-folding or resource data that no host library provides.

- [Resource type classification](../../../core/libs/prx/libSceIcu/Resource.cpp) has no console ABI or behavior verification. `res_getPublicType` (NID `WPrktCwd+iw` in the PS5 3.20 inventory above) takes an unsigned 32-bit resource and returns a signed 32-bit public type, following ICU 65.1 and [ICU 78.1](https://github.com/unicode-org/icu/blob/049e0d6a420629ac7db77256987d083a563287b5/icu4c/source/common/uresdata.cpp). Both use the same mapping of the high four bits; the low 28 bits do not affect the result. Cross-firmware export availability and native behavior remain unverified. Closes when: compared with the console.

- [Locale keyword search](../../../core/libs/prx/libSceIcu/Locale.cpp) has no console ABI or behavior verification. `locale_getKeywordsStart` (NID `wlK146pHnQ4` in the PS5 3.20 inventory above) takes a `const char*` and returns the first `@` or null, following [ICU 68.2](https://github.com/unicode-org/icu/blob/release-68-2/icu4c/source/common/uloc.cpp): the 3.20 inventory NID `BufsAiaX0+s` is the hash of the `icu_68` `BreakIterator::createCharacterInstance` symbol. ICU 77 and later take a `std::string_view`, so a module built from those would accept a string that is not terminated; which ICU version later firmware uses is unverified. ICU dereferences a null locale, which throws here. Closes when: compared with the console.
