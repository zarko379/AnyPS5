## remove [webrtc::VideoFrame::Builder destructor with packet infos]

## change [webrtc::VideoFrame(buffer, timestamp_rtp, render_time_ms, rotation) constructor and destructor]

- [webrtc::VideoFrame(buffer, timestamp_rtp, render_time_ms, rotation) constructor, destructor and video_frame_buffer](../../../core/libs/prx/libwebrtc/src/VideoFrame.cpp) (libwebrtc) - nothing is checked on the console. Follows [video_frame.cc](https://webrtc.googlesource.com/src/+/8d78f5de6c27b2c793039989ea381f1428fb0100/api/video/video_frame.cc), the same at M127, on the 216-byte M134 layout from Clang 19 libc++ probes: the constructor stores the same bytes as upstream, leaving `id_` unset, and takes a reference through guest slot 0; the destructor releases the packet infos as `EncodedImage` does, then the buffer through slot 1; `video_frame_buffer` returns a new reference through the hidden result pointer. A malformed packet info vector throws before anything is released and keeps its reference. A null frame or buffer reference, or a buffer without those slots, throws. Closes when: compared with the console.

## add Public source implementations

- [webrtc::VideoFrame::Builder destructor, set_video_frame_buffer and build](../../../core/libs/prx/libwebrtc/src/VideoFrameBuilder.cpp) (libwebrtc) - nothing is checked on the console. Follows [video_frame.cc](https://webrtc.googlesource.com/src/+/8d78f5de6c27b2c793039989ea381f1428fb0100/api/video/video_frame.cc) and `scoped_refptr` assignment, the same at M127 but for a field name. `set_video_frame_buffer` adds the new reference (guest slot 0), then releases the old one (slot 1). `build` copies every field into the 216-byte frame, adds a buffer and a packet info reference and leaves the processing time unset; a null buffer, which upstream `RTC_CHECK`s, throws `std::runtime_error`. The destructor releases the packet infos and then the buffer. Null arguments or missing slots throw. Closes when: compared with the console.
- [RtpPacketInfos release shared by EncodedImage, VideoFrame and VideoFrame::Builder](../../../core/libs/prx/libwebrtc/src/RtpPacketInfos.cpp) (libwebrtc) - nothing is checked on the console. The `RefCountedNonVirtual` `RtpPacketInfos::Data` of [rtp_packet_infos.h](https://webrtc.googlesource.com/src/+/8d78f5de6c27b2c793039989ea381f1428fb0100/api/rtp_packet_infos.h) (count at 0, entry vector at 8) holds 104-byte `RtpPacketInfo` entries of `rtp_packet_info.h`, whose only allocation is the CSRC vector at 8; members and order are the same at M127 with abseil's optional aliased to `std::optional`. Dropping the last reference validates the vectors, frees each CSRC vector from last to first, the entries and the data with guest `operator delete`; a malformed vector throws and restores the reference. Closes when: compared with the console.
