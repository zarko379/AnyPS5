# libwebrtc

## add Public source implementations

- [webrtc::rtcp::Pli constructor](../../../core/libs/prx/libwebrtc/src/RtcpPli.cpp) (libwebrtc) - not measured on a console. Defaulted in [pli.cc](https://webrtc.googlesource.com/src/+/8d78f5de6c27b2c793039989ea381f1428fb0100/modules/rtp_rtcp/source/rtcp_packet/pli.cc), the same at M127: both SSRCs start at 0. The object gets a host vtable shaped as `rtcp::Nack`'s (complete and deleting destructors, `BlockLength` 12, `Create` writing the header and common feedback as upstream), with the existing empty `D1`. A full buffer without a callback, which upstream only `RTC_DCHECK`s, throws. A null object throws. Closes when: compared with the console.
- [webrtc::rtcp::Remb constructor, destructor and Parse](../../../core/libs/prx/libwebrtc/src/RtcpRemb.cpp) (libwebrtc) - not measured on a console, and the `RTC_LOG` warnings upstream writes on rejected packets are not emitted. Adapted from [remb.cc](https://webrtc.googlesource.com/src/+/8d78f5de6c27b2c793039989ea381f1428fb0100/modules/rtp_rtcp/source/rtcp_packet/remb.cc), identical at M127, on the 48-byte layout of `remb.h`: `Psfb` SSRCs at 8 and 12, `bitrate_bps_` at 16 and the libc++ SSRC vector at 24. As upstream, an invalid bitrate returns false after the common feedback and bitrate are stored; the SSRC vector is reserved to exactly the count with guest `operator new`. The host vtable's `Create` follows upstream. A null object or header, or a payload of 16 bytes or more without data, throws. Closes when: compared with the console.
- [webrtc::rtcp::ReceiverReport constructor](../../../core/libs/prx/libwebrtc/src/RtcpReceiverReport.cpp) (libwebrtc) - not measured on a console. Defaulted in [receiver_report.cc](https://webrtc.googlesource.com/src/+/8d78f5de6c27b2c793039989ea381f1428fb0100/modules/rtp_rtcp/source/rtcp_packet/receiver_report.cc), the same at M127, on the 40-byte layout of `receiver_report.h` (sender SSRC at 8, report block vector at 16, 28-byte `ReportBlock`s of `report_block.h`). The host vtable's destructors free the vector with guest `operator delete`; `BlockLength` and `Create` follow upstream and `ReportBlock::Create`. More than 31 blocks are not rejected, as in a release build. A null object throws. Closes when: compared with the console.
- [webrtc::rtcp::CompoundPacket constructor and destructor](../../../core/libs/prx/libwebrtc/src/RtcpCompoundPacket.cpp) (libwebrtc) - not measured on a console. Defaulted in [compound_packet.cc](https://webrtc.googlesource.com/src/+/8d78f5de6c27b2c793039989ea381f1428fb0100/modules/rtp_rtcp/source/rtcp_packet/compound_packet.cc), the same at M127, on the 40-byte layout of `compound_packet.h` (vector of `unique_ptr<RtcpPacket>` at 16). The destructor deletes the appended packets from last to first, as libc++ `vector` does, through each packet's deleting destructor in guest vtable slot 1, then frees the storage; the host vtable's `BlockLength` and `Create` call slots 2 and 3 of each appended packet. A missing slot throws before anything is deleted; a null object throws. Closes when: compared with the console.
- [webrtc::rtcp::RtcpPacket::Build()](../../../core/libs/prx/libwebrtc/src/RtcpPacket.cpp) (libwebrtc) - not measured on a console. Adapted from [rtcp_packet.cc](https://webrtc.googlesource.com/src/+/8d78f5de6c27b2c793039989ea381f1428fb0100/modules/rtp_rtcp/source/rtcp_packet.cc), the same at M127: the 24-byte `rtc::Buffer` result, returned through the hidden result pointer, gets size and capacity `BlockLength()` (guest slot 2) and guest `operator new[]` storage, and `Create` (slot 3) runs with a null callback. As in a release build, a failed or short `Create` is not checked. An exception from `Create` frees the storage and propagates. A null result, packet or missing slot throws. Closes when: compared with the console.
