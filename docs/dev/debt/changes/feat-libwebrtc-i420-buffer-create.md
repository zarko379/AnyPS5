## add Public source implementations

- [webrtc::I420Buffer::Create(width, height, stride_y, stride_u, stride_v)](../../../core/libs/prx/libwebrtc/src/I420Buffer.cpp) (libwebrtc) - invalid dimensions or a size above `INT_MAX` throw through `NotImplemented_nid_no_patch`: M134's [i420_buffer.cc](https://webrtc.googlesource.com/src/+/8d78f5de6c27b2c793039989ea381f1428fb0100/api/video/i420_buffer.cc) `RTC_CHECK`s them, M127 does not, and the module's revision is unknown; not measured on a console. Otherwise both build a 48-byte `RefCountedObject<I420Buffer>` (count at 40) holding one reference, with `AlignedMalloc`'s 64-byte aligned guest `malloc` block (start pointer stored before the data). Its host vtable follows `ref_count.h`, `video_frame_buffer.h` and `ref_counted_object.h` at both revisions: reference counting, destructors, type, sizes, the existing `ToI420`, `GetI420`, `CropAndScale`, `GetMappedFrameBuffer`, chroma, stride and plane functions, `storage_representation` ("?") and `HasOneRef` at slot 20. Closes when: the revision is identified and compared with the console.
